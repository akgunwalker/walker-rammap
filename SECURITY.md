# Güvenlik

Güvenlik açığını herkese açık bir issue içinde paylaşmayın. Repository sahibine
GitHub profili üzerinden özel olarak ulaşın ve sorunun etkisini, tekrarlama
adımlarını ve varsa örnek çıktıyı bildirin.

Walker RAMMap yalnızca `127.0.0.1` üzerinde dinler. Ayarlar, geçmiş ve tanılama
verileri kullanıcı profilinde yerel olarak saklanır.
